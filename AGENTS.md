# MiaRoseEhrlich.com

## Project Goals

Personal website for software engineer and writer Mia Ehrlich.

Tone:

- restrained
- literary
- atmospheric
- technical
- calm

Avoid:

- startup aesthetics
- cyberpunk
- portfolio-template design
- overengineering
- unnecessary abstractions

## Technical Stack

- React
- Vite

Prefer:

- simple components
- readable code
- minimal dependencies

## Design Principles

- prioritize typography
- prioritize spacing
- prefer warm color palettes
- maintain a sense of place
- restraint over visual complexity

## Development Philosophy

- make small incremental changes
- preserve simplicity
- avoid speculative architecture
- do not introduce libraries without justification

## Current Priority

Create a simple homepage with:

- name
- introduction
- projects section
- writing section

No CMS.
No backend.
No authentication.
