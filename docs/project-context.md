# Project Context — miaroseehrlich.com

## Overview

This is a personal/professional website for software engineer and writer Mia Rose Ehrlich.

The site should feel:

- restrained
- atmospheric
- literary
- technical
- calm
- intentional
- slightly strange
- emotionally grounded

Avoid:

- startup aesthetics
- “creative technologist” branding language
- productivity culture vibes
- cyberpunk clichés
- overexplaining symbolism
- excessive animation
- overengineered frontend architecture
- portfolio-template energy

The project is intentionally iterative and exploratory.

The site is not meant to function as:

- a traditional UX portfolio
- a corporate personal brand
- or a maximalist art project

It should feel authored, lived-in, and emotionally coherent.

---

## Core Themes

The site exists at the intersection of:

- backend systems
- web applications
- writing
- atmosphere
- memory
- digital space
- emotional architecture
- sense of place

Important concept:

> “digital spaces with a sense of place”

The project is interested in digital environments that feel:

- inhabited
- textured
- spatial
- emotionally real
- temporally layered

Not:

- sterile
- frictionless
- hyper-optimized
- or purely functional

## Visual Direction

### Preferred Palette

- warm black
- charcoal
- bone/off-white
- dusty sage
- faded rust
- tobacco brown
- muted desert tones

Avoid:

- pure white
- neon
- glossy gradients
- hyper-modern startup palettes

### Typography

Typography should feel:

- literary
- restrained
- warm
- serious without pretension

Serif fonts are preferred for now.

Avoid:

- generic startup sans-serifs
- excessive font mixing
- trendy portfolio typography systems

### Layout Philosophy

The layout should prioritize:

- spaciousness
- calm pacing
- readability
- atmosphere
- restraint

Minimal content is acceptable.

The current successful direction:

- large heading
- sparse copy
- careful spacing
- emotional clarity through restraint

---

## Current Homepage Direction

Warm dark palette. Serif typography. Sparse professional copy. Desert image treated as background residue, not hero image. Goal: restrained, literary, technical, sense of place.

Current copy direction:

“Mia Rose Ehrlich”

“Software engineer based in Santa Fe.”

“Backend systems, web applications, writing, and digital spaces with a sense of place.”

This wording is close to correct because it balances:

- technical identity
- atmosphere
- and specificity

without sounding:

- overly poetic
- overly corporate
- or self-mythologizing

## Important Aesthetic Constraint

The project should avoid:

> aesthetic dishonesty.

Every visual or textual choice should feel:

- emotionally true
- internally coherent
- and naturally aligned with the creator’s actual sensibility.

The goal is not:

> uniqueness performance.

The goal is:

> authored presence.
